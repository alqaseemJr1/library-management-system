# library-management-system
A simple Python library management system.
📚 Library Management System

A simple Library Management System built with Python.

🚀 Features

* Add new books
* View saved books
* Store books in a text file
* Menu-driven interface
* Keeps previously saved books

🛠️ Technologies Used

* Python
* File Handling
* Lists
* Loops
* Functions
* User Input

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the Python file:

python library.py

4. Follow the menu instructions.

📋 Example Menu

===== LIBRARY MENU =====
1. Add Book
2. View Books
3. Exit
